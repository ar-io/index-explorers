# Wavehaus

`wavehaus-*.woff2` are ArDrive's licensed typeface, converted from the OTF
files ArDrive web ships (Light, Book, SemiBold, Bold). They are here with the
ArDrive team's permission (2026-11-09) for the ArDrive explorer only. They are
not covered by this repository's AGPL licence: don't reuse them in another
project or page.
